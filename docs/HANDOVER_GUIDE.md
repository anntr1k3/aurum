# 📦 ИНСТРУКЦИЯ ПО ПЕРЕНОСУ ПРОЕКТА AURUM НА ДРУГОЙ КОМПЬЮТЕР

Этот документ содержит пошаговую инструкцию по переносу исходников сайта, приложения и контекста на другой ПК для работы с **Google Antigravity**.

---

## 🗂️ Что включено в пакет передачи:

1. **`docs/ANTIGRAVITY_CONTEXT.md`** — Полный архитектурный и функциональный контекст проекта, написанный специально для агента Antigravity.
2. **`website/`** — Полные исходники статического веб-сайта Aurum (`index.html`, `styles.css`, `app.js`, шрифты `fonts/`).
3. **`src/`** — Исходный код C# .NET 8 / WPF (`Aurum.Core`, `Aurum.Infrastructure.Windows`, `Aurum.App`).
4. **`tests/`** — Набор автономных тестов (`Aurum.Core.SelfTests`, 59 тестов).
5. **`docs/`** — Архитектурная документация, Product Brief, Roadmap.
6. **`build_release.ps1`** — Скрипт сборки автономного EXE.
7. **Архивы в папке `dist/`**:
   * `dist/aurum-website.zip` — Исходники сайта для публикации/хостинга.
   * `dist/aurum-antigravity-context-bundle.zip` — Полный архив контекста и документации.

---

## 🚀 Быстрый старт на новом компьютере:

### Шаг 1. Перенос файлов
Скопируйте папку проекта `Aurum` на новый компьютер (например, в `C:\Users\<Имя>\Documents\Aurum` или любую другую директорию).

### Шаг 2. Открытие в Antigravity
1. Запустите Google Antigravity на новом компьютере.
2. Откройте директорию проекта как рабочее пространство (Workspace).
3. При первой команде Antigravity передайте ему:
   > *"Ознакомься с файлом docs/ANTIGRAVITY_CONTEXT.md — там находится полный контекст архитектуры, стек и текущее состояние Aurum."*
4. Агент мгновенно восстановит 100% контекста проекта и сможет сразу продолжать разработку, добавлять фичи или править интерфейс.

### Шаг 3. Проверка окружения и тестов
В терминале PowerShell на новом компьютере:
```powershell
# 1. Прогон всех 59 тестов
dotnet run --project .\tests\Aurum.Core.SelfTests

# 2. Сборка релиза
powershell -ExecutionPolicy Bypass -File .\build_release.ps1

# 3. Просмотр сайта
python -m http.server 4173
# Открыть в браузере: http://localhost:4173/website/
```
